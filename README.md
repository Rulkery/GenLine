# 🌳 GenLine

> 🧪 **Статус проекта:** На стадии исследования и проектирования (R&D / WIP).  
> Проект представляет собой переосмысление моего учебного приложения для ведения семейной истории.

---

## 🎯 Идея проекта

Создать удобный, красивый и отзывчивый инструмент для визуализации генеалогических связей, хранения биографических данных и мультимедийных архивов семьи.

---

## 🛠 Выбор технологий (в процессе)

---

## 📌 Планируемый функционал

- Интерактивное визуальное древо с удобным зумом и навигацией
- Подробные карточки родственников с таймлайном событий
- Безопасное локальное хранение данных и медиафайлов
- Импорт и экспорт данных
